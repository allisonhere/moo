Moo は [allisonhere/moo](https://github.com/allisonhere/moo) で開発されています。[Herdr](https://github.com/herdrdev/herdr) の成果物を基にしており、Herdr の著者による著作権表示と [Apache License 2.0](https://github.com/allisonhere/moo/blob/master/LICENSE) を保持します。

## 文書の変更

継承した Herdr の文書を Moo 向けに変更しています。製品の説明、コマンド、パス、環境変数、インストールと更新の手順、プラットフォームの制限、リンク、Moo 固有の機能を更新しました。Wiki では MDX を Markdown に変換しています。過去のリリース文書は当時の名前を保持します。

## 互換性のための名前

`herdr-plugin.toml`、`min_herdr_version`、`ui.toast.herdr`、統合フックのファイル名、`herdr:` で始まる報告元は互換性のために残っています。リファレンスにある名前をそのまま使用してください。これらは製品名を変更するものではなく、元プロジェクトのインストーラーで Moo をインストールできるという意味でもありません。
