## Linux バイナリ

チェックサム検証付きインストーラーは Linux x86_64 と aarch64 に対応し、既定で `~/.local/bin` に配置します。`MOO_VERSION` でリリースを固定し、`MOO_INSTALL_DIR` で配置先を変更できます。

```sh
curl -fsSL https://raw.githubusercontent.com/allisonhere/moo/master/scripts/install.sh | sh
```

## ソースからビルド

Rust と Zig **0.16.0** を用意してください。Zig を `PATH` に追加するか、`ZIG=/path/to/zig` を指定します。Linux または macOS では次を実行します。

```sh
git clone https://github.com/allisonhere/moo
cd moo
./scripts/install-moo.sh
```

ソース用スクリプトは固定された依存関係で `moo` をビルドします。Windows では Rust と Zig のネイティブ環境で `cargo build --release --locked --bin moo` を実行し、必要な ConPTY ランタイムを `moo.exe` と同じ場所に置いてください。制限は [Windows 対応](/docs/windows-beta/) を参照してください。

## 起動と確認

インストール先を `PATH` に追加し、プロジェクトのディレクトリで起動します。`ctrl+b q` でデタッチし、`moo` で再接続します。

```sh
moo --version
moo
```

## 更新

バイナリのインストーラーを再実行するか、目的のソースを取得して `./scripts/install-moo.sh` を再実行してください。`moo update` は更新方法を説明するだけで、バイナリをダウンロードしません。元プロジェクトの Homebrew、mise、Nix、stable/preview の手順は Moo をインストール・更新しません。

## ファイルと削除

リリース版は `~/.config/moo` と `~/.local/state/moo`、デバッグ版は `moo-dev` を使います。Windows の設定は `%APPDATA%\moo` にあります。バイナリを削除してもデータは残ります。これらのディレクトリを削除する前に必要なセッションをバックアップしてください。
