Moo is developed in [allisonhere/moo](https://github.com/allisonhere/moo). It builds on [Herdr](https://github.com/herdrdev/herdr), copyright the Herdr authors, under the [Apache License 2.0](https://github.com/allisonhere/moo/blob/master/LICENSE).

## Documentation changes

Moo documentation adapts inherited Herdr documentation for Moo. Changes include product descriptions, commands, filesystem paths, environment variables, installation and update instructions, platform caveats, links, and Moo-specific features. Wiki pages are converted from MDX to Markdown. Historical release snapshots retain their original identity.

## Compatibility names

Some implementation names remain unchanged for compatibility: `herdr-plugin.toml`, `min_herdr_version`, `ui.toast.herdr`, integration hook filenames and `herdr:` report sources. Use these exact names where the reference documents them. They do not change the product name or imply that upstream installers install Moo.
