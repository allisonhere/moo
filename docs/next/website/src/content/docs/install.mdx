## Linux binaries

The checksum-verified installer supports Linux x86_64 and aarch64. It installs to `~/.local/bin`; set `MOO_VERSION` to pin a release and `MOO_INSTALL_DIR` to choose another directory.

```sh
curl -fsSL https://raw.githubusercontent.com/allisonhere/moo/master/scripts/install.sh | sh
```

## Build from source

Install Rust and Zig **0.16.0**. Put Zig on `PATH` or set `ZIG=/path/to/zig`. Run the source installer on Linux or macOS:

```sh
git clone https://github.com/allisonhere/moo
cd moo
./scripts/install-moo.sh
```

The source installer builds `moo` with the locked dependencies. On Windows, build with `cargo build --release --locked --bin moo` in a configured native Rust/Zig environment and keep the required app-local ConPTY runtime beside `moo.exe`. See [Windows support](/docs/windows-beta/) for limitations.

## Run and verify

Ensure the install directory is on `PATH`. Start Moo from your project directory. `ctrl+b q` detaches; `moo` reattaches.

```sh
moo --version
moo
```

## Update

Rerun the binary installer, or pull the desired source revision and rerun `./scripts/install-moo.sh`. `moo update` explains how to install a newer build; it does not download a binary. The upstream Homebrew, mise, Nix, and stable/preview channel instructions do not install or update Moo.

## Files and removal

Release builds use `~/.config/moo` and `~/.local/state/moo`; debug builds use `moo-dev`. On Windows, config is under `%APPDATA%\moo`. Removing the binary leaves your data in place. Back up any sessions you need before deleting those directories.
