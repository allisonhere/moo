## Linux 二进制文件

安装脚本支持 Linux x86_64 和 aarch64，并验证校验和。默认安装到 `~/.local/bin`；用 `MOO_VERSION` 固定版本，用 `MOO_INSTALL_DIR` 修改安装目录。

```sh
curl -fsSL https://raw.githubusercontent.com/allisonhere/moo/master/scripts/install.sh | sh
```

## 从源码构建

安装 Rust 和 Zig **0.16.0**。将 Zig 加入 `PATH`，或设置 `ZIG=/path/to/zig`。在 Linux 或 macOS 上执行：

```sh
git clone https://github.com/allisonhere/moo
cd moo
./scripts/install-moo.sh
```

源码脚本使用锁定的依赖构建 `moo`。Windows 用户需要配置原生 Rust/Zig 环境，执行 `cargo build --release --locked --bin moo`，并将所需的 ConPTY 运行时放在 `moo.exe` 旁。限制请参阅 [Windows 支持](/docs/windows-beta/)。

## 运行与验证

将安装目录加入 `PATH`，在项目目录中启动。`ctrl+b q` 分离，`moo` 重新连接。

```sh
moo --version
moo
```

## 更新

重新运行二进制安装脚本，或拉取所需源码后再次执行 `./scripts/install-moo.sh`。`moo update` 仅解释更新方法，不下载二进制文件。原项目的 Homebrew、mise、Nix 和 stable/preview 通道安装说明不适用于 Moo。

## 文件与移除

发行版使用 `~/.config/moo` 和 `~/.local/state/moo`，调试版使用 `moo-dev`。Windows 配置位于 `%APPDATA%\moo`。移除二进制文件后数据仍然保留。删除这些目录前，请备份需要的会话。
